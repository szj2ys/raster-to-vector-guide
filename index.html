Raster to Vector: Tools, Formats, and How to Check the Output

A raster image (PNG, JPG, WebP) is a grid of pixels. A vector image (SVG, DXF, EPS) is a set of mathematical shapes — paths, curves and fills — that scales to any size without blurring. Converting one to the other is called tracing, and the quality of the result depends almost entirely on the tool and the kind of artwork.

Start with the workflow

  • PNG or JPG to editable SVG: use a raster-to-vector trace when the artwork should remain editable in Illustrator, Figma, Inkscape, or a browser-based SVG editor. See the PNG-to-SVG workflow or JPG-to-SVG workflow.
  • Several files at once: batch tracing is useful when logos, icons, or stamps share the same source format. See batch image-to-SVG conversion.
  • Cut files for CNC or laser: SVG is the editable exchange format; DXF is often the downstream cut format. See image-to-DXF conversion.
  • Check before production: an SVG can contain a bitmap disguised as a vector file. Follow how to check whether an SVG is a real vector.

Which kind of image are you tracing?

Tracing works best on art that is fundamentally shapes:

  • Logos, icons, line art, stamps, single-colour silhouettes — flat, high-contrast art traces cleanly into a small, editable vector file.
  • Photographs — a photo has millions of subtle colour transitions and no clean edges to follow; a trace either looks wrong or produces a file so heavy it defeats the purpose. Keep photos raster.

How to verify an SVG actually contains vectors

  1. Open the file as text. A real vector file is full of <path d="…"> elements. A fake one contains a single <image> element pointing at a base64 data URI — that is a bitmap in an SVG wrapper.
  2. Zoom to 800%. Real paths stay crisp; an embedded bitmap pixelates.
  3. Check the size. A photo traced into genuine paths is usually far larger than the source PNG, because thousands of nodes cost bytes.
A file extension is not a format. A PNG renamed to .svg is still a PNG.

Choosing a format

  • SVG — the default for the web, icons and design tools. Text-based and editable.
  • DXF — for CNC routers, laser cutters and vinyl plotters. Check that the file contains LWPOLYLINE/POLYLINE entities (real cut paths) and not an IMAGE section.
  • EPS / PDF — for print workflows that expect PostScript or vector PDFs.

Getting the numbers, not vibes

Claims about tracing quality are easy to make and hard to check. A useful approach is to trace a fixed image set with each tool and compare edge fidelity, node counts and file size side by side. An offline, reproducible benchmark of that kind — with the harness and raw JSON behind every number — is available from the pic2svg benchmark and its public benchmark repository.

Hosted-tool disclosure: pic2svg posts the image to its own API for tracing; it does not hand the file to a third-party vectorizer. The current hosted product allows 12 traces after sign-in, with tracing and preview free and downloads on the paid plan. Check the current pricing before relying on those limits.
